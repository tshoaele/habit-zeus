# Zeus — Daily Discipline & Habit Tracker ⚡

A private, offline-first habit tracker with streak tracking, 30-day analytics heatmap, habit CRUD, date navigation, JSON backup/restore, and PWA support.

## ⚡ Features

- **Offline-First & Private**: Data is stored locally in `LocalStorage`.
- **Dynamic Habit Management**: Create, edit, and delete habits with custom categories (*Fitness, Mindfulness, Deep Work, Health*), frequencies, and time-of-day slots (*Morning, Afternoon, Evening, Anytime*).
- **Streak & Rank System**: Live streak calculation and Discipline Rank (*Initiate → Disciple → Spartan → Olympian → Zeus Sovereign*).
- **30-Day Heatmap & Matrix**: Visual consistency heatmap and per-habit performance tracking.
- **Date Navigation**: Jump back to past dates to view or backfill history.
- **JSON Backup & Import**: Export data for safekeeping or import across devices.
- **PWA Support**: Installable Web App with ServiceWorker support (`sw.js`).
